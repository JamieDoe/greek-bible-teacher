the unmodified web fonts from
https://software.sil.org/downloads/r/gentium/Gentium-7.000.zip (downloaded 2026-09-24, zip
sha256 `313e64963ba27851356060a725d36ce01680e5c5c63f46e4b40f15741c043e21`).

renaming the font under the OFL.
